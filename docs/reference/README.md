# Референс

- `reference.webp`: целевой вид игры (портретный кадр: садовая дорожка, кусты с цветами, деревянные кашпо и ворота, арка вдали, HUD-капсулы). Главный образец для сверки.
- `baseline/`: кадры текущей игры «до» доработки (появятся в Фазе 0).
- `progress/<фаза>/`: кадры по ходу работы для проверки пользователем.

Иконка огня в HUD референса намеренно заменена своей (см. `docs/handoff/REWORK_PLAN.md`).
