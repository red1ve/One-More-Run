# Project

## Name

One More Run

## What are we building?

A small HTML5 hypercasual game for Yandex Games.

The player controls an object moving through a procedurally generated track and tries to achieve the highest possible score.

## Target audience

Players who want short gaming sessions on desktop or mobile.

A typical session should take approximately 30–120 seconds.

## Core player motivation

The main motivation is improving the personal best score.

The player should frequently feel:

"I almost beat my record. One more try."

## Problem we solve

The game provides a quick, immediately understandable gameplay experience that can be played without installation or registration.

## Business goal

Publish the first game on Yandex Games and test whether a small independently developed HTML5 game can attract real players and generate the first advertising revenue.

Revenue is not guaranteed.

The first release is also an experiment.

## Product priorities

1. Fun core gameplay.
2. Player retention.
3. Quality and polish.
4. Performance.
5. Monetization.

Monetization must not destroy the player experience.

## Platform

Primary:

Yandex Games.

Supported:

- desktop;
- mobile.

## Languages

Initial:

- Russian;
- English.

## Scope

The first release must remain small.

Do not add large systems before the core gameplay has been tested with real users.
